# Slide 5 — What is Programming?

### Script

Now we come to one of the most important concepts in this lecture:

**What is Programming?**

Programming is the process of writing instructions that tell a computer how to perform specific tasks.

In simple words:

**Programming means giving instructions to a computer so that it can perform a required task.**

For example, suppose we want a calculator to add two numbers.

The computer needs to receive the numbers as input.

It needs to process those numbers.

It needs to perform the addition.

And finally, it needs to display the result.

These steps are instructions.

When these instructions are organized into a form that a computer can execute, they become part of a program.

You can remember this simple flow:

**Instructions → Program → Computer → Result**

Instructions tell the computer what to do.

A program organizes those instructions.

The computer executes the program.

And the user receives the required result.

This basic idea is behind almost every software system.

# Slide 7 — How Programming Works

### Script

Now let's understand the basic workflow of programming.

Programming does not always begin by immediately writing code.

### Step 1 — Identify the Problem

First, we need to understand what problem we are trying to solve.

For example, suppose we want to create a calculator program that adds two numbers.

The problem is:

We need to take two numbers as input and calculate their sum.

### Step 2 — Plan the Solution

Next, we decide how the solution should work.

What will the input be?

What processing is required?

What should the output be?

### Step 3 — Write Instructions Using a Programming Language

Now we convert our planned solution into instructions using a programming language.

Later in this course, we will use **Python** for this purpose.

### Step 4 — Computer Executes the Program

The computer takes those instructions and executes them.

### Step 5 — User Receives the Expected Output

Finally, the result is presented to the user.

So the overall flow is:

**Problem → Plan → Instructions → Execution → Output**

This basic workflow will be extremely important throughout our programming journey.

# Slide 14 — Program vs Programmer

### Script

There are two terms that beginners often confuse:

**Program** and **Programmer**.

They sound similar, but they mean completely different things.

A **program** is a set of instructions that a computer can execute.

It is the digital creation.

For example, a calculator application can be considered a program.

A **programmer**, on the other hand, is the person who creates the program.

The programmer understands the problem, designs the solution, writes the code, tests it, and maintains it.

So remember this simple distinction:

**Program = The instructions/software created for the computer.**

**Programmer = The person who creates the program.**

You can think of it this way:

The program is the **creation**.

The programmer is the **creator**.

This distinction is simple, but it is important to understand before moving forward.

# Slide 22 — Ada Lovelace

### Script

Now let's take a short look at an important figure in the history of programming:

**Ada Lovelace.**

Ada Lovelace is widely recognized as the first computer programmer.

During the 1840s, she wrote an algorithm intended to be executed by a machine.

An algorithm is essentially a sequence of instructions designed to solve a problem or perform a task.

What makes this particularly interesting is that this work happened long before modern programming languages and modern computers became common.

Her work represents an important early example of algorithmic thinking and machine-oriented instructions.

So the fundamental idea we are learning today — giving a machine a structured set of instructions — has a long history.

As we continue learning Python, we will be writing our own instructions for computers, but using a modern programming language.
