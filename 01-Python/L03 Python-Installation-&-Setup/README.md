## 🗺️ Understanding Windows PATH

The lecture explains PATH using a simple analogy.

**PATH is a Windows system setting that acts like a map.**

It tells Command Prompt where the Python executable is located.

The basic relationship is:

**Command Prompt → Windows PATH → Python Executable File**

When Python is correctly added to PATH, Windows can locate Python when the user enters Python commands from Command Prompt.

Without the correct PATH configuration, Windows may not recognize the `python` command.

---

## ✅ Verifying the Installation

After installation, students verify Python using Command Prompt.

The command shown in the lecture is:

```text
python --version
```

A successful installation should return a Python version number such as:

```text
Python 3.x.x
```

If a version number appears, the installation has been successfully detected.

---

## 🛠️ Common Installation Errors

The lecture presents a diagnostic matrix for three common problems.

### Error 1 — `python` Command Not Recognized

**Possible cause:**

- Python was not added to PATH.
- Command Prompt needs to be restarted.

**Solution:**

- Restart Command Prompt.
- If the problem continues, reinstall Python and make sure the PATH option is selected.

---

### Error 2 — Wrong Python Version Installed

**Possible cause:**

- An incorrect or outdated installer was downloaded.

**Solution:**

- Download the latest stable version directly from the official Python website.

---

### Error 3 — Multiple Python Versions Installed

**Possible cause:**

- Older Python installations are conflicting with the new installation.

**Solution:**

- Remove older Python versions through Windows Settings.
- Keep the latest required version.
