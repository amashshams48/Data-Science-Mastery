## 💻 What is Visual Studio Code?

**Visual Studio Code**, commonly called **VS Code**, is a source-code editor used for writing and working with programs.

For our Python course, VS Code will provide the environment where we will:

- Create Python files.
- Write Python code.
- Edit and organize programs.
- Run Python programs.
- View program output.
- Work on larger Python projects as the course progresses.

VS Code is lightweight, widely used, and supports Python through extensions.

---

## ⚙️ Installing Visual Studio Code

The practical setup begins by installing VS Code on Windows.

The general workflow is:

1. Download Visual Studio Code from its official website.
2. Open the installer.
3. Follow the installation steps.
4. Complete the installation.
5. Launch Visual Studio Code.

Once VS Code opens successfully, the coding environment is ready for the next setup step.

---

## 🐍 Setting Up Python Support in VS Code

VS Code can support many programming languages.

For Python development, we need to install the **Python extension**.

The basic workflow is:

1. Open Visual Studio Code.
2. Open the Extensions section.
3. Search for the Python extension.
4. Install the appropriate Python extension.
5. Wait for the installation to complete.

The extension provides Python-specific development features inside VS Code.

---

## 📁 Creating the First Python File

After setting up VS Code, the next step is to create a Python source file.

Python source files use the:

```text
.py
```

extension.

For example:

```text
hello.py
```

The `.py` extension tells us that the file contains Python source code.

This is the type of file we will use throughout the course to write Python programs.

---

## 👋 Writing the First Python Program

The first program introduces the basic `print()` function.

Example:

```python
print("Hello, World!")
```

This is a simple Python statement that displays text as output.

### Understanding the Statement

```python
print("Hello, World!")
```

- `print` is a built-in Python function.
- The text inside quotation marks is a string.
- `"Hello, World!"` is the message we want to display.
- The `print()` function sends that message to the program's output.

When the program runs, the expected output is:

```text
Hello, World!
```

---

## ▶️ Running the Python Program

After writing the program, students run the Python file from VS Code.

The purpose of this step is to connect the three basic elements:

**Code → Execution → Output**

We write Python instructions in the `.py` file.

The Python interpreter executes those instructions.

The result appears in the output area.

This is the first practical demonstration of how the programming concepts learned in earlier lectures are applied.

---

## 🔍 Understanding the First Program

Although the first program is very small, it introduces several important ideas.

### Source Code

The instructions written by the programmer are called source code.

Example:

```python
print("Hello, World!")
```

### Execution

The Python interpreter processes and executes the program.

### Output

The result produced by the program is:

```text
Hello, World!
```

This creates a simple programming cycle:

**Write → Run → Observe Output**

Students will use this cycle repeatedly throughout the course.
