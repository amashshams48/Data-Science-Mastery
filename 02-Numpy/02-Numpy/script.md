**What is NumPy?**

NumPy stands for **Numerical Python**.

# 📘 Slide 02 – Why Was NumPy Created?

## 🎯 Objective

Explain the problem that existed before NumPy and why it was developed.

## 🗣️ Speaking Script

Now let's understand why NumPy was created.

Python is an amazing programming language. It is simple, readable, and beginner-friendly.

But when developers started using Python for scientific research and numerical computing, they discovered a problem.

Python Lists were not designed for handling massive numerical calculations.

Imagine working with millions of numbers. Every mathematical operation would become slower and consume more memory.

Researchers and engineers needed a faster and more efficient solution.

To solve this challenge, NumPy was developed.

Instead of relying on traditional Python Lists, NumPy introduced a completely optimized array structure that performs calculations much faster while using memory efficiently.

In simple words, NumPy was created to make numerical computing powerful, fast, and scalable.

---

# 📘 Slide 03 – Python Lists vs NumPy Arrays

## 🎯 Objective

Compare Python Lists with NumPy Arrays.

## 🗣️ Speaking Script

This is one of the most important concepts in today's lecture.

Many beginners ask,

"If Python already has Lists, why should we learn NumPy?"

The answer lies in performance.

Python Lists are general-purpose containers. They can store different types of data like integers, strings, booleans, and even objects in the same list.

While this flexibility is useful, it also makes numerical calculations slower.

NumPy Arrays, on the other hand, are specially designed for numerical data.

They store data more efficiently in memory and perform mathematical operations much faster.

If your project involves calculations, statistics, Data Science, Machine Learning, or Artificial Intelligence, NumPy Arrays are always the better choice.

Throughout this course, we will use NumPy Arrays instead of Python Lists for numerical computing.

# 📘 Slide 04 – Core Features of NumPy

## 🎯 Objective

Introduce the main advantages of NumPy.

## 🗣️ Speaking Script

Now let's explore the features that make NumPy so powerful.

The first feature is **High Performance**.

NumPy performs calculations much faster than standard Python Lists.

The second feature is **Memory Efficiency**.

NumPy stores data in a compact and optimized format, reducing memory consumption.

Another important feature is **Powerful Mathematical Functions**.

Instead of writing long loops, NumPy provides built-in functions for calculations, statistics, linear algebra, and much more.

NumPy also supports **Multidimensional Arrays**, making it easy to work with tables, matrices, and higher-dimensional data.

Finally, NumPy integrates perfectly with almost every Data Science library available in Python.

These features are the reason why NumPy has become an essential skill for every Data Scientist.

# 📘 Slide 05 – Understanding ndarray

## 🎯 Objective

Explain the core data structure of NumPy.

## 🗣️ Speaking Script

Every library has one central concept.

For NumPy, that concept is the **ndarray**, which stands for **N-dimensional Array**.

You can think of ndarray as the heart of NumPy.

It allows us to store data in one dimension, two dimensions, three dimensions, or even higher dimensions.

For example,

A simple list of marks represents one-dimensional data.

A classroom result sheet represents two-dimensional data.

Medical scans, videos, and scientific simulations often involve three-dimensional or even higher-dimensional data.

Instead of creating different data structures for different situations, NumPy handles everything using ndarray.

This is one of the biggest reasons why NumPy is so flexible and powerful.
