## 📖 About This Repository

Welcome to **Data Science Mastery**!

This repository is designed to help students learn Data Science step by step using a structured roadmap. Every topic is explained with theory, practical implementation, assignments, GitHub resources, and projects.

This repository follows the same learning path as the YouTube course and is continuously updated with new lectures and resources.
